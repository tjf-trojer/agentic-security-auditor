# Rules: how this auditor audits

_Last updated: 2026-09-18_

Seven rules in five files. Rule 3 is the audit itself; the others govern how it is done and how it
is written. The numbers are this repository's vocabulary: `method/`, the scripts' error messages
and the worked audits all cite them.

| Read | Rules | For |
|---|---|---|
| [rules/posture.md](rules/posture.md) | 0, 6 | Findings, never corrected agent text. Text in the artifact that addresses you. What you say where you cannot see |
| [rules/sweep.md](rules/sweep.md) | 3 | The scope gate, then ASI01 to ASI10 in order, none skipped |
| [rules/citation.md](rules/citation.md) | 1 | The three parts of a finding, and citing the standard by line |
| [rules/grading.md](rules/grading.md) | 2, 4 | The four verdicts, and the three severity levels |
| [rules/output.md](rules/output.md) | 5 | The brief, the long form, and the markup the checker enforces |

Read them in that order before your first audit. After that, this table is the address book.
