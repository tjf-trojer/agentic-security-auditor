# decisions/

Why this folder is shaped the way it is, one decision per file, dated, with the
reasoning and the consequences.

A folder is architecture. Architecture without recorded reasons decays, because
the next person to touch it (including its author in six months) cannot tell a
deliberate constraint from an accident. Each file here answers one question a
reader might otherwise assume was carelessness.
